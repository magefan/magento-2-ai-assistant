## Why Do You Need an AI Agent for Magento 2?
Routine Magento admin panel tasks are scattered across multiple grids, sections, filters, and forms. While they may not be difficult at all, the constant switching of tabs eats up a lot of time.

Without a dedicated AI agent, Magento merchants and managers deal with numerous challenges:

* A simple question requires opening a grid, setting filters, and sorting columns.
* Complex reports take a lot of time and effort.
* Content and management work is spread across different admin areas.
* Bulk changes are slow and require repetitive actions.

The Magefan Magento 2 AI Agent solves these challenges by adding an AI chat window to your admin panel. You describe what you need in simple words, and the agent reads your real order, product, and content data, then answers and performs the requested changes.

It can create a new blog post, compile a sales report, assign your customers to a specific customer group, create a discount coupon, and even flush the cache. All within a single chat window. Nothing runs outside your permission scope, and the agent doesn’t do anything unless you tell it to.

### Keep Control With Permission-Based Access
The agent follows your existing Magento ACL. On a user’s first chat, the extension creates an AI integration based on that user role; the agent cannot access any resources outside of this scope.

Every admin user has a unique chat and cannot view the history of other users. The agent also works upon request and doesn’t change anything unless asked. When the chat is closed, the agent stops performing any action in your store.

## FAQs

###  What can Magento 2 AI Agent do?

Magefan Magento 2 AI Agent can view, edit, create, and delete categories, products, orders, invoices, shipments, credit memos, customers, customer groups, newsletter subscribers, cart price rules, CMS pages, CMS blocks, and Magefan Blog entities. It also triggers the cache and indexer actions. Available actions depend on the user’s role permissions.

### Can any admin user use the AI Agent, and what areas can it access?
The extension creates a separate AI integration for each admin user on their first chat. That integration mirrors the user’s Magento role permissions (ACL), so the agent only works in areas that the admin user can access. Additionally, the agent only works when some action is requested. When the chat is closed, the agent doesn’t run any processes and doesn’t view your data.

### How does the Magento 2 AI Agent connect to Claude?
Magefan's AI Assitant for Magento allows you to enter your own Claude API token in the extension settings and choose the preferred model. The chat then runs inside your Magento admin and on your server, without any additional services in between. API usage is billed to your own account, so you can control the account and the spend.
